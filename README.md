## 🎮 About The Game (In progress)

**Machine and Blood** is an asymmetrical horror-survival multiplayer game built on Roblox, inspired by games like *Dead by Daylight*. 

In this dark, high-stakes arena, players are divided into two opposing sides: the survivors, who must use wits and teamwork to escape, and the machine/killer, hunting them down without mercy. 

### 🛠️ Technical Overview (Engine & Scripting)
As the **Core Scripter** of this project, I engineered the gameplay mechanics and systems from scratch using **Luau** in **Roblox Studio**. 

* **Asymmetrical Multiplayer Framework:** Implemented efficient matchmaking, state management, and round-based logic to handle 1 vs. Many gameplay.
* **Optimized Luau Scripting:** Focused on writing clean, object-oriented (OOP), and highly optimized code to ensure smooth replication and low latency between server and client.
* **Game Mechanics:** Programmed interactive elements, player abilities, and core survival/hunting systems.
