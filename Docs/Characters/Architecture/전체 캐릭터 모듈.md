# 전체 생존자 아키텍쳐

피격자 (생존자 Rig): HumanoidRootPart 하위에 크기 고정된 DamageBox를 항상 달고 다님.  (움직이거나 애니메이션을 춰도 이 박스는 언제나 몸통 중심에 고정되어 있음)

공격자 (살인마 Rig): 마우스 클릭(or E키)을 하면, 살인마 정면에 순간적으로 공격 범위용 투명 파트(AttackHitbox)를 생성. <-- 기존 방식에서 단순 옵션 변경 아닌 destory () 사용

판정: 서버에서 이 AttackHitbox 내부에 생존자의 DamageBox가 겹쳤는지 딱 한 프레임 스캔 후, 데미지 주고 AttackHitbox는 즉시 Destroy()
