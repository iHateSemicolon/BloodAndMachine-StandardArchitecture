# 모든 캐릭터들 같은 이 구조로 짜주세요!
//모듈 스크립트 필요

```mermaid
graph TB
    %% 첫 번째 섹션: Gui
    subgraph Gui ["[ Gui ]"]
        subgraph mainFrame ["mainFrame"]
            TextButton["TextButton"]
        end
    end

    %% 두 번째 섹션: char(rig)
    subgraph char ["[ char(rig) ]"]
        subgraph Rig ["Rig"]
            subgraph HumanoidRootPart ["HumanoidRootPart"]
                DamagePart["DamagePart(Part)"]
            end
        end
    end

    %% 세 번째 섹션: Skills
    subgraph Skills ["[ Skills ]"]
        SkillText["캐릭터마다 달라지겠지만<br>각 스킬마다 전용 히트박스 필요"]
    end
```mermaid
## Gui
ScreenGui
  ㄴmainFrame
    ㄴTextButton

## char(rig)
Rig
 ㄴ HumanoidRootPart
   ㄴ DamagePart(Part)

## Skills
캐릭터마다 달라지겠지만 각 스킬마다 전용 히트박스 필요
